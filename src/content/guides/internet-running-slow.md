## Test in the right order

A single speed test tells you very little on its own. Run three tests, ideally within a few minutes of each other:

1. **Wired to the router** with an Ethernet cable, on a modern laptop.
2. **Wi-Fi near the router**, on the same laptop or phone.
3. **Wi-Fi in the room where the problem happens.**

Write down download, upload, and latency for each. Use the same test service each time.

| Result | Likely cause |
| --- | --- |
| Wired fast, Wi-Fi near router fast, far room slow | Coverage problem |
| Wired fast, Wi-Fi near router slow | Wi-Fi settings or router wireless fault |
| Wired slow, provider plan higher | Line, modem, router, or provider |
| All tests fine, one app slow | Device or app problem |

## Improve the wireless path

### 1. Restart the router and modem

Power off the router and modem, wait 30 seconds, and power the modem on first. Wait for its lights to stabilise, then power the router. This clears temporary faults and re-establishes the connection.

### 2. Move the router

Place it high, central, and in the open. Avoid cupboards, floors, metal furniture, and the back of a TV. A small move can change coverage more than a settings change.

### 3. Choose a less crowded channel

On 2.4 GHz, use channel 1, 6, or 11 and let the router scan for the quietest option. On 5 GHz, use the router’s automatic selection unless you have a reason to fix a channel. Interference from neighbours is common in flats and dense housing.

### 4. Use the 5 GHz band where possible

5 GHz is usually faster at short range. Connect devices that stay near the router to 5 GHz and leave 2.4 GHz for distance and older devices. If the router combines both bands under one name, test with separate names to see which performs better.

### 5. Check for background traffic

Open the router’s device list or the operating system’s network usage screen. Game updates, cloud photo backups, and video calls can use most of the connection. Pause large downloads and test again.

## Check the line and equipment

### 6. Test directly at the modem

If it is safe and your setup allows it, connect a laptop by cable directly to the modem, briefly, and run a speed test. This separates the router from the incoming line. You may need to power-cycle the modem when changing the connected device.

### 7. Check the plan and provider status

Confirm the speed you pay for. Check the provider’s status page for an outage in your area. If the wired speed is consistently below the plan, contact the provider with your test results and the times.

### 8. Update router firmware and device drivers

Use the manufacturer’s official firmware for the router and the laptop maker’s driver for the Wi-Fi adapter. A firmware update can fix throughput bugs, but follow the instructions carefully and keep the device powered.

## If it is still slow

- **Try a different test server** to rule out a slow test endpoint.
- **Test another device** to see whether the problem follows one device.
- **Disable a VPN** temporarily. A distant VPN server can halve throughput.
- **Check DNS** by trying a reputable resolver, but do not expect DNS to fix raw speed; it mainly affects how quickly names resolve.
- **Ask the provider for a line test** before replacing the router.

> [!WARNING]
> Do not use unofficial “speed booster” tools that change registry settings, disable security features, or install browser extensions with broad permissions. A slow connection is rarely fixed by software that asks for more access than it needs.

## Confirm the fix

Repeat the three tests at the same time of day. A real improvement shows up in the same location and on more than one device. If only one test improves, you may have measured a temporary quiet period rather than a fix.
