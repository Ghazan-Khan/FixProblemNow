## Start with the simple causes

### 1. Open the service directly

Type the service’s address into the browser or use a saved bookmark. Do not use a link from an email, text, or search ad. Check the domain carefully; a convincing login page on the wrong domain is a phishing attempt.

### 2. Check typing and autofill

Turn off caps lock and confirm the keyboard layout. A password saved years ago may be out of date. Type it manually once, or reveal it in the password field if the service allows. Remove any trailing space.

### 3. Try a private window or the official app

A private browser window avoids a stale session and some extensions. If the web login works but the app does not, update or reinstall the app. If the app works but the browser does not, clear the site’s cookies and try again.

## Use the official recovery flow

### 4. Choose Forgot password

Use the link on the official login page. Enter the account address and complete the verification steps. Recovery may use an email, phone number, authenticator app, or a trusted device. Do not use a “password reset” link from an unexpected message.

### 5. Check the recovery details

If the code does not arrive, confirm the recovery email and phone number are current. Check spam and blocked messages for the email, and check that the phone can receive SMS. If the details are outdated, use the provider’s account recovery form.

### 6. Handle two-factor authentication

If you lost the authenticator device, use a saved recovery code or the provider’s account recovery process. If a code is rejected, check the device clock; authenticator codes depend on accurate time. Never send a code to someone who asks for it.

### 7. Wait out a temporary lock

Repeated failed attempts can lock an account for a period. Stop trying, note the message, and wait as instructed. If the lock does not clear, use the provider’s support route rather than guessing more passwords.

## If the account may be compromised

### 8. Check recent activity

After you regain access, review recent sign-ins, devices, recovery details, and connected apps. Remove anything you do not recognise. Change the password from a trusted device.

### 9. Enable stronger security

Turn on multi-factor authentication, save recovery codes, and update the recovery email and phone. Use a unique password that you do not reuse elsewhere.

### 10. Contact the provider

If the password or recovery details were changed by someone else, use the provider’s compromised-account route. Provide the information they request through official channels. Do not pay a third party that promises to recover the account.

> [!WARNING]
> No legitimate support agent needs your password or a one-time code. If someone asks for either, end the conversation and report it. Account recovery fraud is common after a data breach.

## Confirm the fix

Sign in on the web and on one trusted device, receive a test verification code, and confirm the recovery details are correct. Review recent activity and remove unknown sessions. If the account still behaves strangely, change the password again from a clean device and contact the provider.
